# v0.1.17 受控验证方案

目的：减少 SFT 带来的非思考复述和任务执行退化，同时保留中文身份。原生模型也会出现的知识或安全问题另行记录，不用它们掩盖这次退化是否改善。

**v0.1.16 用于受控诊断，v0.1.14 用于检验是否真正改善，最终候选由对照结果决定。** 本版已完成数据准备和 CPU 检查，尚未训练。

## 数据只改一项

以冻结的 v0.1.16、1,357 条数据为父版本。从此前通用内容审核的“未发现明显问题”记录中，选取 32 条中文、现有两次曝光、正文可独立回答的样本。本轮已逐条重读所选正文，覆盖代码、计算、解释、写作及缺信息澄清；不是随机样本，也不声称已完成所有外部事实核验。

每条原来有两份相同的 Thinking 记录。保留较早一行；较后一行将 `<think>…</think>` 内的思考文字换为空思考块，块后的答案字节原样保留。问题不加 `/no_think`，原有正文中的解释和计算步骤也不删除。

保持以下内容：

- 总行数、问答正文、每种问答的两次曝光、原有顺序和 shuffle seed。
- 234 次身份曝光及答案权重 3；其余权重不变。
- v0.1.16 的 175 条 System 分配及文本，包括其新增 32 条任务示范。
- 英文和混合语言记录；已有已知内容问题本轮也未同时修订。

32 是本次小规模诊断的范围，不是最低有效数量或已验证的最佳配比。如果结果不改善，只能说明这个改动规模没有显示效果，不能排除整个监督分布假设。选择详情见 [32 条前后对照](SAMPLES.md)。

## 变化如何解释

去掉思考监督后，正文会更早出现在上下文中，总监督 Token 和损失分母也会减少。因此这是一项“通用非思考监督构建”的实验，同时包含上下文长度、位置与损失组成的变化；不能将效果纯归因于一个标签。

本次删除 20,859 个监督 Token，减少约 1.37%；新增的非思考通用正文监督为 18,653 个 Token。这些正文原来已经监督过，本次只是把其中一次放到空思考前缀后。没有新增问题、答案或曝光。

已知语料内容问题另留在原审核清单。这个候选用于归因，不因实验改善就自动成为可发布模型。

## 训练方案

从原始 `Qwen/Qwen3-8B` 新建 LoRA，不接着 v0.1.16 权重训练，不合并或叠加旧 LoRA。

沿用原运行环境与配方：Swift 4.4.2，BF16，1 epoch，batch 1 × 累积 16，lr 1e-4，r8/alpha32/dropout0.05，all-linear，max_length2048，warmup0.05，seed/data_seed42，gradient checkpointing；`default+t008_identity3_ignore_empty_think` 和 `preserve_thinking=false` 保持。

批准后仍是 3 步 Smoke，加一次从基座重新初始化的 Full；Smoke 权重不续训。Full 预计 85 个优化器步，以最终完整 epoch 权重为本轮候选。可保存第 50 步用于后续固定文本诊断，但不拿它与最终步反复挑分。TensorBoard 记录训练，退出后归档到 ClearML；沿用原方式，不新建调度或进度桥接。

本轮只准备与检查。数据通过 CPU 检查不等于训练获准或效果通过。

## 比较与决定

使用原版、v0.1.14、v0.1.16 和本候选，保持同一修正后的 vLLM 模板；带 System 时四者使用同一份 v0.1.16 System，不拿旧版 System 分数充当同条件比较。

开发集 140 题：此前选定的 128 道退化/正常对照，加 8 道中文身份和 4 道 JSON 题。全部属于开发回归，不声称独立验收；题目与近似改写不加入本次训练。

1. 非思考＋System：140 题，各 3 次。
2. 非思考、无 System：其中 32 道复述题和 8 道身份题，各 3 次。
3. Thinking＋System：16 道哨兵题，各 1 次，只筛明显副作用，不估计身份稳定率。

四模型共有 2,224 个比较槽位，现有结果可复用 1,066 个，预计补生成 1,158 次。复用按原轮次取结果，不按好坏挑选；开跑前再核对权重、模板、System 和请求参数，若漂移则先重算计划，不自行扩大请求数。模板文件哈希与 Deployment 模板对象哈希是两种对象，已按实际文件证据核对。

以最近 1,340 次生成约 26.4 分钟作参考，1,158 次按相近吞吐约 23 分钟；考虑题长、Thinking 与切换，暂留约 30–50 分钟生成预算。此数不含训练、装载和人工判读，不是时限承诺。本轮没有执行这些请求。

判据见 [评测说明](EVALUATION.md)，逐题题面及要点见 [本地开发题](development/CASES.md)。优先看相对两版 LoRA 的复述、任务完成、事实保持和中文身份；原版用于测量仍未恢复的差距。**只优于 v0.1.16、不及 v0.1.14，不能叫退化修复成功。**

若出现改善且无新的明显退步，下一步再安排未参与开发的独立小集确认；本轮不自动发布。如果没有改善，固定数据再单独讨论学习率实验，不同时换 System、增加曝光或改多项配方。
