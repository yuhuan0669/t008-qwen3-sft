# v0.1.9 相对上一轮的配置差异

比较对象为 **v0.1.8 + 身份损失 ×3**，不是未加权的 v0.1.8 初始训练。保留 Qwen3/ms-swift 的 SFT 基础路线和已核验的身份损失扩展。

| 项目 | 本版 |
| --- | --- |
| 基座与训练方式 | 原始 `Qwen/Qwen3-8B` + 新 LoRA；不续训旧 LoRA |
| 训练数据 | 只替换 5 条中文记录，总数仍为 1275；身份曝光仍为 216 |
| 权重实现 | 原插件字节不变，重新生成消息哈希索引；身份 3，其余 1，空思考与提示 0 |
| 新增监督 | 两条身份的非空短思考也按 3 倍训练；三条业务记录的短思考按 1 倍训练 |
| LoRA | r=8、alpha=32、dropout=0.05、all-linear，均不变 |
| 学习率与批次 | 1e-4、单卡 batch=1、梯度累积 16，均不变 |
| 轮数与长度 | 1 epoch、约 80 个优化步骤、max_length=2048，均不变 |
| 其他训练参数 | BF16、梯度检查点、warmup=0.05、seed/data_seed=42 均不变 |
| 思考与 System | `preserve_thinking=false`，空思考屏蔽不变；训练不加 System |
| 训练记录 | TensorBoard 指标，训练后按既有流程归档 ClearML；本次未训练、未建 Task |

训练命令只更换数据路径、身份插件所在路径和输出目录；Smoke 仅更换输出目录。完整机器差异见 [config-diff.json](config-diff.json)。数据哈希、版本号和证据路径随新版本更新。

评测沿用已验证的 vLLM 聊天模板，绑定上一轮 40 次推理已检查的新 System；Non-thinking 预算为 2048、Thinking 为 4096，其他采样参数保持原方案。Thinking 的预算由思考与正文共同使用。原有开发题和正式留出集不改写；本轮聚焦中文，英文身份延后。这些评测配置没有部署到 UAT。

CPU 检查通过只表示输入与权重配置正确。本版尚无新 LoRA 或新模型分数，下一步才是训练与开发验证。
