# 身份答案概率与损失诊断

状态：CPU 编码检查通过，525条去重记录的监督 token 可回读，三份 LoRA 文件哈希通过；GPU 诊断等待本次 UAT 暂停许可。

用户授权范围：对比原版、Full2、v0.1.7、v0.1.8；不增加训练曝光、不训练；需要暂停 UAT 时先告知。历史暂停许可不复用于本次。

## 检查什么

1. **训练答案是否拟合：** 取各版本实际自我认知训练记录，按完整 messages 去重；Full2 105种、v0.1.7/8各210种（包含有/无 `/no_think` 的形式差异）。使用实际 ms-swift 模板及空思考屏蔽方式编码，计算原版与该候选对完全相同正确答案的损失、逐 token 概率、排名，以及名称 token 的单独指标。重复次数仅作来源记录，不运行训练。
2. **自然生成是否偏离：** 六个公开问法包括中英文“你是谁”的有/无标记版本，以及中文模型全称、公司全称。四个模型均不加 System，沿用修正后的聊天模板，在两种模式下贪婪生成，共48次。Non-thinking上限256，Thinking上限1024；超限如实保留，不能据此判断“没学会”。
3. **Thinking 路径影响：** 分别测空思考结束后的正确答案概率，和模型真实生成思考、正常闭合后的正确答案概率。后者固定闭合后的换行分隔符，不改思考文字；没有闭合则该项缺测，不强制截断补答案。

旧模型按旧名称、v0.1.8按新中文名称评价；原版分别计算对应答案，保证每项候选与原版的目标字节一致。不同名称的整体序列概率不能直接横比。

## 如何解释

- 训练式问法的正确名称仍低概率、排名靠后，自由生成也错误：支持拟合不足。
- 训练答案明显优于原版、训练式问法可生成，但自然问法失败：支持问法泛化不足。
- 空思考入口正确，而真实 Thinking 后概率下降或生成改成错误身份：支持思考路径影响。
- 可能同时存在；不强行二选一。低整体损失也可能掩盖少数关键名称 token 的失败，因此保留逐 token 结果。
- `exp(-平均损失)` 是平均每个 token 概率的几何均值，**不是整句回答正确率**。教师强制计算已提供前面的正确答案 token，不能替代自由生成证明。
