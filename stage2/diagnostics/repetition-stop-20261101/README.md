# 固定续文概率诊断

本轮由用户“开始”授权，只比较原版、v0.1.14、v0.1.22 身份损失3倍与1倍四份权重。沿用此前“可无需授权就暂停UAT”的许可，使用完GPU后恢复原Deployment副本数、核对完整spec、模型别名及外部健康。

从上一轮已保存回答中选取两条近似复述、两条正文循环、一条思考循环，另加三条正常对照。共8例、21个位置、每处3条固定续文、四份权重，共252项评分。选择和正确参考均在读取本轮概率前冻结。

所有模型使用相同的System、修正后的聊天模板、输入和固定续文。保留实际请求及解析后回答的原始空白；思考正文边界补回解析器移除的 `</think>`。CPU核对每条续文不会改变前缀的分词、上下文未截断、基座和LoRA文件哈希一致。模型卷只读。

比较未过滤概率、实际采样参数过滤后的首Token概率、排名、固定续文前48 Token的平均负对数概率。每处只计算一次起始分布，避免不同续文长度造成第一步数值比较偏差。另记录两种采样配置在同一分布上的过滤结果；这只是概率变换，不是重新生成。

EOS分支用于检查停答倾向；在思考尚未交付正文时，EOS不等于正确回答。正确的切换是 `</think>` 后交付正文。正确参考是人工指定的反事实，不能写成模型自行生成的成功结果。不同长度续文的平均损失也不等于完整答案概率。

本轮不训练、不修改训练数据、不生成新答案、不调用Judge、不发布模型。案例来自已知失败，不能估计总体失败率，也不能单凭它们判定某一条训练数据为因果根源。原始问题、响应、逐Token评分仅本地保留，Git保存脚本、协议、哈希、检查摘要及结论。

GPU评分预计5—10分钟；独立恢复看护进程在15分钟时触发恢复，主进程任何退出也执行恢复。CPU准备在UAT正常运行期间完成。
