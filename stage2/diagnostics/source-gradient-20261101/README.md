# 分来源训练信号诊断

目标：判断当前数据的通用、身份、其他业务／格式监督，分别把已知复制／循环、事实与身份续文的局部概率往哪个方向推。先完成这一步，再决定唯一一个来源消融；不直接补样本或训练新候选。

使用 v0.1.22 既有 checkpoint-50、checkpoint-66 两个真实保存状态。全量1047次曝光逐条原生编码：通用752、身份234、其他61；其他细分业务43与格式／短通用18，避免混称行业知识。重复记录可共享确定性前后向，但按原次数累计，训练数据与身份权重3保持原样。

15个既有问题／固定续文位置，每个带、不带相同System，共30个探针。含复制入口、首次循环、正常结束、身份名称及事实对比。固定前缀与两份续文首次不同的Token构成 `q=logP(错误续文Token)-logP(正确续文Token)`；不把它解释成整个回答的错误率。内容仅本地保存，不混入训练。

在每个固定检查点计算各来源的全库加权CE梯度，分母为928890个未加权有效Token；保持原始0/1/3权重。计算 `-grad(q)·grad(L_source)`：正值表示该来源负梯度会在一阶近似下提高所选错误Token相对支持，负值表示降低。另以实际Adam二阶状态形成固定对角缩放作敏感性对照；不构造优化器，不执行step。正常梯度与Adam缩放方向若不一致，不挑有利的一个下结论。

原训练使用AdamW、梯度累积16、裁剪1、权重衰减0.1及余弦学习率。此处关闭dropout，计算确定性局部导数；全库梯度不是按时间推进的训练更新，也不包含下一步动量、裁剪和权重衰减。checkpoint-66保存的学习率已为0，因此缩放分析仅为方向诊断，不是“继续训练下一步”的预测。参数顺序与504个优化器槽位形状逐项核对。

开始前核对原生掩码、归一化、数据及权重哈希，并用原生Swift损失验证节省显存的计算及梯度。结束后核对检查点内存和磁盘权重未变。只计算导数和固定文本概率；不生成回答、不调用Judge、不修改训练语料、不发布。UAT保持暂停，不自动恢复。

判读事先约定：只有某来源的方向在相关上下文及两个检查点有一致支持时，才优先建议对应来源消融；否则记录混合或不确定。即使一致，也只证明局部贡献，不能追溯为历史退化唯一根因。旧测试题仅用于诊断，不是新的独立验收。
