## 判断更新

1. 不支持把问题简单归为最后16步训练过头。第50步已支持相同复制路径，但本轮没有更早检查点，不能定位首次形成时间，也没生成第50步自由回答。
2. 身份不是本题复制路径的必要因素。已有关闭身份候选保留该路径，本轮没有测到明确减弱；不代表身份对所有任务无影响。
3. 61次业务/格式监督或它们与通用监督的训练交互，仍是优先线索。本轮给出了关闭它们后入口减弱的直接概率证据，和历史复述计数下降相互补充；尚未证明哪一条或哪一类负责。
4. v27仍能进入复制并继续复制指令。继续随机删通用样本或增加身份曝光，当前缺乏针对性。

下一步建议先定向核对61次示范（业务43、格式18）的输入/答案结构与监督段；若做下一次训练因果对照，只恢复其中一类，其他全部不变。也可对已定位的实际入口重新计算分来源梯度作为选组线索；旧梯度探针不是这条完整实际路径，不能直接套用其排名。本轮不自动追加训练。
