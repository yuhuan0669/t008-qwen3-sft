# 执行前约定
假设：v0.1.22的历史复述，与固定错误回答相对正确回答的偏好增强有关。
唯一干预：LoRA权重。零更新、第8步、v0.1.22；零更新最后重复，检查数值波动。
其余：同一题、两种System、冻结模板、串行、相同固定参考、相同镜像和模型；不生成整段回答，不训练。
主要指标：每条错误参考的平均logp减去每条正确参考平均logp；比较v22相对零更新和第8步的差。两条错误×两条正确、两种System分别报告，不能混成总分。
支持：同一System下四个差值均为正且超过max(0.01 nat/token,5倍零更新重复最大变化)。这是工程判定，不是统计显著性或真实失败率。
反对：四个差值均为负且超过同一阈值。其他方向不一致或变化不足记未定。仅开头词变化不支持。
下一步：支持则用既有分来源消融权重核对来源；反对则停止将本单题机制泛化；未定则不调参数不训练。两个System结论分别保留。
参考及判定在运行前冻结；完成后不因分数改阈值或参考。
