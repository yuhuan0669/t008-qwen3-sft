# v0.1.22单题假设检验结果

**预登记结论：反对本轮固定参考偏好假设。不追加训练，不将该指标继续泛化为历史复述根因。**

## 开始前约定

[PREREG.md](PREREG.md)在本轮评分前写入。假设是：v0.1.22的严重复述，对应两条既有复述回答相对正确回答的偏好增强。唯一干预为LoRA权重，零更新、第8步、v0.1.22；零更新末尾重复。题目、两种System、模板、串行读取、参考回答、镜像和基座不变。

执行前回读已有原始回答：供热题v0.1.22带System3/3完全复制，不带System3/3近似复述；原版对应6次未复述。原版部分答案仍错误，不能称原版全部合格。样本量小，历史差异是选择诊断案例的依据，不是整体现象的因果证明。

## 执行结果与判定

40次固定文本评分，未训练、未生成新的整段回答。vLLM max_tokens=0在当前实现内部仍计算1个Token，40次成功usage合计40；不能标成底层零计算。参数和LoRA哈希在运行中核对通过。诊断Pod已删除，UAT保持0副本，Deployment spec不变。

评分：某错误参考的平均logp减去某正确参考的平均logp；再计算v22相对对照权重的差。这里的平均分不是整段生成概率或真实失败率。两种错误×两种正确共4项，每个System和对照分别判断。

零更新首尾重复平均NLL最大变化=0。按预登记阈值max(0.01 nat/token,5倍重复波动)，实际阈值0.01。以下所有差值均小于-0.01，方向全部与假设相反：

## 更新判断

1. 撤回将“16条候选改变开场概率”直接外推为v22严重复述解释的做法。当前证据链没有接上。
2. 不能因正确答案条件概率提高，就宣布“模型已经学会，纯属生成跑偏”。固定前文评分和从用户输入开始的实际生成不是同一件事。
3. 本轮参考冻结自16条候选的两条近似复述，**并非v22逐字复制题面的原始输出**。负结果只反对这套固定参考及指标的解释，不排除v22对其实际逐字复制路径偏好增强。这是测量覆盖限制，不能在结果出来后换参考改判“支持”。
4. 正确参考只覆盖两种写法，整个答案平均分还会稀释早期决定性分叉；这两项局限保留，不据此倒改本轮判据。

## 结果对应的下一步

按预登记执行“反对”分支：停止用此单题固定参考平均分解释整库退化；不调学习率、不加曝光、不启动训练。

后续先从已有归档回查v22实际逐字复述与原版回答：锁定原始请求、输入Token、解码参数及实际复制路径。若提出新的逐Token假设，须另写前缀、唯一干预、判定与停止条件再执行。不能把本轮换一套参考后的结果算作同一假设通过。
