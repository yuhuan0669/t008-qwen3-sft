# v0.1.22 训练与中文对照结果

**清洗后的 v0.1.22 没有解决退化，不建议发布。** 非思考复述仍在，循环重复及其导致的截断明显增多。部分无依据事实和有害帮助减少，但任务完成没有相应改善。保留本候选和完整证据用于定位，未追加训练或部署。

一次 3 步 Smoke、一次全新 LoRA 的 66 步／1 epoch Full 完成；新增 556 份中文回答，复用同协议历史回答 1668 份，共比较 2224 份。UAT 原配置和三个模型别名已恢复，1/1 就绪，内部健康 200、外部连续两次 200。暂停至恢复核验约 **22 分 32 秒**。

与 v0.1.16 相比，无System复述本批减少 8 次，但按题重采样的差值区间仍跨零，尚不能认定稳定改善；带System则没有改善。与 v0.1.14 相比，两种非思考条件都更差。思考仅测 16 份回答，其中复述专项10份，不能据此宣称思考模式已解决问题。

## 2. 身份、JSON与风格

| 身份完整交付 | 原版 | v0.1.14 | v0.1.16 | v0.1.22 |
|---|---:|---:|---:|---:|
| 非思考＋System／24 | 21 | 24 | 23 | **23** |
| 非思考、无System／24 | 0 | 11 | 0 | **8** |
| 思考＋System／4 | 3 | 4 | 3 | **4** |

v0.1.22 无System有14/24答对身份口径，但只有8/24同时完成问题、没有业务能力编造或循环等问题；出现名称或短句反复生成至截断。说明身份有部分拟合，仍不稳定。原版没有训练定制身份，其无System身份分数仅作参照，不能记为原版通用能力缺陷。

四模型在相同 JSON Schema 约束下均 **14/14** 通过结构及值核对。这证明当前约束路径可用，不证明模型不带Schema也能稳定输出JSON。

420份非思考＋System回答中，中文限定／对冲句式命中分别为21、8、9、13份，身份尾语分别7、5、3、6份。它们是词式观察，不自动算错误。本轮中文输出未出现英语 `does not establish`、`alone does not`，不能据此排除英文风格风险；英文评测仍延后。

## 3. 训练与推理链路核验

- 冻结数据1047条：通用752次曝光、身份234次、其他61次；本轮未改任何样本、曝光、System或训练配方。训练仍无System。
- Qwen/Qwen3-8B重新初始化LoRA，未接续旧Adapter；BF16、r8／alpha32、dropout 0.05、all-linear、lr 1e-4、batch1×累积16、max_length2048、1epoch、身份损失×3及空think屏蔽保持不变。
- 复用同字节原生CPU编码结果，运行库及源码哈希重新核验；最长2041 token，1047条完整进入原生加载和训练管线，无超长、丢行、空监督。CPU使用raise、训练保持delete，由成员守卫约束零丢行。
- 实际Full命令与冻结命令一致，66步结束，loss和梯度记录有限；纯训练约519秒，平均train_loss约1.04。训练损失下降不代表行为质量通过。
- 模型包在ClearML上传后回读，并保存本地；包哈希一致。Full Task：`3a5e5707eb7549d1ae257ae7fd87a78a`；OutputModel：`427ea25eb85647d6ac06cda3656ebc98`。
- 修正后的vLLM聊天模板、System和Schema沿用冻结版本。196种实际服务端输入token序列与本地渲染完全一致；556次生成，0技术重试；所有原始请求/响应已逐份核对。
- 非思考预算2048、温度0.7、top_p0.8；思考预算4096、温度0.6、top_p0.95；两者top_k20、repetition_penalty1，不传请求seed，并发8。未改解码参数以掩盖问题。

相对于v0.1.14，本轮还经历了数据修订、隔离、总量1325→1047和步数83→66；相对于v0.1.16，训练System分布也不同。因此结果支持“**这套清洗数据＋现有配方不足以解决退化**”，不能单独证明某句修文、数据量或某个训练参数是根因。也未发现本轮数据错装、LoRA未加载、静默丢行或模板未应用的证据。

## 4. 下一步建议

先停止扩修数据和扩大题量。本候选保留用于诊断，不替换现有服务。

下一个训练对照优先只检验 **身份损失倍率3→1**：保持v0.1.22数据、曝光、空think处理、System、学习率和其他参数不动，同样从原始基座开始。复用本轮556份和历史对照，重点观察复述、循环、任务完成与无System身份之间的取舍。当前证据没有证明3倍就是根因；这是一个可单独排查、且已在外评中提出的因素。身份加权token份额约2.81%，不能用曝光次数相乘声称“150倍梯度”。

如该单因素仍无改善，再基于实际输出和监督分布决定下一项，不同时调整身份曝光、System、思考格式和多个超参数。本报告仅提出下一步，**未修改插件、未准备新数据版本、未启动下一轮训练**。

## 5. 证据和限制

这是历史失败题富集的开发诊断集，包含已暴露题目，不是独立验收集、总体错误率或正式安全测试。旧结果按完全相同的协议复用，但不共享请求seed，运行批次不同。按题重采样区间也仅用于本开发集解释，不作总体显著性承诺。
