**先前判断得到哪些支持，哪些需要收回**

1. **身份损失并未失效。** 关闭后无 System 身份由8/24变为0/24，符合此前正确名称概率受到身份梯度推动的证据。有 System 仍能回答身份，主要说明提示词可提供名称，不能据此称身份已写入权重。
2. **不能继续把全部退化归于身份曝光或3倍倍率。** 本轮身份来源梯度确实为0，复述仍为16/48和6/48，且出现3次循环截断。剩余来源或其共同训练过程足以在这个配方下伴随该现象；尚不能区分752次通用与61次其他来源，也不能推论所有行业 SFT 都会退化。
3. **删除身份监督不是修复方案。** 带 System 任务失败减少7次，但至少一项业务失败只从57/84降到55/84；无 System 事实错误增加10次。部分回答从照抄变为认真续写错误结论，因此“少复述”不等于“会做题”。
4. **局部梯度不能直接预测重训轨迹。** 第一步在 G007 和 P20-G0274 找到身份梯度推动复制续文的方向。本轮 G007 带 System 仍3/3复述；P20-G0274反而1/3→2/3。G007无System复述3/3→1/3，但任务仍3/3失败、事实错误0/3→3/3。它们没有验证“关闭身份后这两题会恢复”的强预测。保留局部耦合证据，收回把它当作自由生成改善保证的推断。

G0243、G1038在此次冻结历史对照及新生成中均未发生循环，各3次，不能用这几个零值验证其首次循环梯度的作用。逐题预期和结果分别见 [预登记](evaluation/hypothesis-before-generation.json)、[对照](evaluation/hypothesis-result.json)。

可直接查看的失败包括：G007仍把总风量当成新风依据并讨论撤保障；G1202把“零值误当空值”写反；G1038把正确原话改成“已确认解除”；B7-R237仍按年龄排除真实电表记录。它们属于任务、事实或边界问题，不能统一计作复制错误。

**现在最值得验证的下一步**

建议下一次只做一个互补来源消融：**关闭752次通用来源的监督，保留234次身份和61次其他来源**，仍保留1047行、分母、步数及其他参数。用现有全来源和本次关闭身份结果作对照，继续复用相同208次规模的中文检查；不同时改身份倍率、System、长度或补数据。本建议尚未执行。

它要回答：移除通用蒸馏监督后，能否保住身份，并恢复非思考任务执行？若复述减少且任务/事实恢复，优先处理通用来源及其交互；若仍复述，则再考虑共同的61次来源或更一般的监督/更新机制。两边都出现复制仍不证明“身份与通用都无关”，可能是多来源各自足以诱发，或共同来源在起作用。后续每一步都应有这种可区分的预测，不再仅凭总 loss 或单个指标反复调倍率。
